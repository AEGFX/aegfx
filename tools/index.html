Browser tools for people who build and run show content.
Nothing uploads. Every file stays on your machine.

They live at slidesize.com and are built and maintained by Andrew Brandse.

Presentation Tools

Slide Size Calculator

PX → CM

Work out the right slide dimensions for any screen or canvas.

Open on SlideSize

PPT Report

Pre-flight

Pre-flight summary for graphics ops. Fonts, videos, hidden slides, click counts and speaker notes in one sortable report.

Open on SlideSize

Media Extractor

PPT / KEY → files

Pull every embedded asset out of a PowerPoint or Keynote deck with pixel dimensions and metadata.

Open on SlideSize

PDF to Slides

PDF → PNG + PPTX

Drop a PDF, get a folder of numbered images plus a PowerPoint deck with one image per slide.

Open on SlideSize

List Builder

XLSX → PPTX

Drop a spreadsheet of names and get a deck of lists that restyles from the Slide Master.

Open on SlideSize

Font Extractor

Embedded → TTF

Pull the fonts embedded in a deck back out as ordinary .ttf or .otf files.

Open on SlideSize

EMF Extractor

Hybrid EMF → PDF

Pulls the full quality PDF hidden inside Mac EMFs back out and batch converts to PNG for Windows bound decks.

Open on SlideSize

Deck Compare

v1 vs v2
